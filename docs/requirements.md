# 需求规格说明

## 项目概述
故事大纲分析软件（StoryOutline）是一款 Windows 桌面应用，通过接入 DeepSeek 大模型 API，自动分析本地长篇文章/小说，提取结构化故事大纲，帮助作者和编辑快速把握全书剧情脉络。

## 目标用户
需要分析长篇小说/文章剧情结构的内容创作者、编辑、读者。

---

## 功能需求

### FR-01：文件导入
- 支持导入 TXT 纯文本文件
- 支持导入 Word 文档（.docx）
- 支持导入 PDF 文件
- 自动检测 TXT 文件编码（UTF-8/GBK/GB2312）

### FR-02：章节拆分
- 自动识别常见章节标记：`第X章`、`Chapter X`、`第X回` 等
- 支持用户自定义章节识别规则（正则表达式）
- 拆分后展示章节列表，支持用户手动调整：
  - 合并相邻章节
  - 拆分某章为多章
  - 重命名章节标题

### FR-03：第一步分析 — 章节大纲
- 对每一章调用大模型，提取以下五个要素：
  - 激励事件（Inciting Incident）
  - 进展纠葛（Progressive Complications）
  - 危机（Crisis）
  - 高潮（Climax）
  - 结局（Resolution）
- 分析结果结构化展示

### FR-04：第二步分析 — 阶段性总结
- 每分析完 50 章，自动对所有已分析的章节大纲进行一次总结
- 总结内容：这 50 章的主要剧情进展、关键转折、人物变化

### FR-05：第三步分析 — 全书故事线
- 所有章节分析完成后，对第二步的所有阶段性总结进行概括
- 输出内容：整本书的故事线脉络，包括核心冲突、高潮分布、全局走势

### FR-06：断点续传
- 分析进度自动保存（本地 JSON 文件）
- 软件关闭后重新打开，可加载未完成的项目继续分析
- 支持多个项目并存（每个项目独立保存）

### FR-07：结果导出
- 支持导出为格式化 Word 文档（.docx），含标题层级和规范排版
- 支持导出为纯文本文件（.txt）

### FR-08：API 配置
- 用户填写 DeepSeek API Key
- 支持选择模型版本
- 支持设置超时时间和重试次数

---

## 非功能需求

### NFR-01：可用性
- 界面简洁直观，非技术人员可独立操作
- 所有操作不超过 3 次点击完成
- 提供清晰的操作反馈（进度条、状态提示）

### NFR-02：性能
- 文件解析：100 万字文件 < 10 秒
- API 调用：单次超时默认 120 秒，支持自动重试
- 界面响应：操作响应 < 500ms，不卡顿

### NFR-03：兼容性
- 操作系统：Windows 10 / Windows 11
- 无需安装 Python 或其他运行环境（打包为独立 .exe）

### NFR-04：安全性
- API Key 本地加密存储
- 文章内容仅保存在用户本地，不上传到除 DeepSeek 外的任何服务器

---

## 约束条件

- 开发语言：Python 3.11+
- UI 框架：PySide6
- 打包方式：PyInstaller（单文件 .exe）
- AI 服务：DeepSeek API（兼容 OpenAI 接口格式）
