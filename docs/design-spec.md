# UI 设计规范

## 设计原则
- **简洁至上**：每个界面只展示当前最必要的信息
- **渐进呈现**：先展示总览，点击后展开详情
- **即时反馈**：所有操作都有明确的视觉反馈（进度条、状态文字、颜色变化）

## 配色方案（淡蓝色主题）

### 主色调
| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#F0F6FB` | 全局窗口背景，柔和淡蓝 |
| 侧边栏背景 | `#E3F0F8` | 左侧章节列表，稍深区分 |
| 卡片/面板背景 | `#FFFFFF` | 结果卡片、对话框背景 |
| 主按钮 | `#5B9BD5` | 主要操作按钮（导入、分析、导出） |
| 按钮悬停 | `#4A8AC4` | 鼠标悬停时加深 |
| 强调色 | `#3B7DD8` | 进度条、选中状态、链接 |
| 成功色 | `#52C41A` | 分析完成、成功状态 |
| 警告色 | `#FAAD14` | 提示、警告状态 |
| 错误色 | `#FF4D4F` | 错误、失败状态 |

## 布局规范

### 主窗口（1280 × 800 px，可缩放）
```
+----------------------------------------------+
|  菜单栏（文件 | 设置 | 帮助）                    |
+--------+-------------------------------------+
|        |   标签栏（原文 | 章节大纲 | 阶段总结 | 故事线）|
| 章节    |  +----------------------------------+
| 列表    |  |                                   |
| 树形    |  |   内容展示区                        |
| 导航    |  |   （QTextBrowser / QScrollArea）    |
| (280px)|  |                                   |
|        |  +----------------------------------+
+--------+-------------------------------------+
|  状态栏：第 X/Y 章 | 已分析 Z% | API 状态       |
+----------------------------------------------+
```

### 按钮规范
- 主按钮：高度 36px，圆角 4px，内边距 16px
- 次要按钮（取消、返回）：白底 + 边框 `#D9D9D9`
- 危险按钮（删除、重置）：白底 + 红色边框
- 按钮间距：至少 12px

### 间距规范
- 组件之间：16px
- 相关元素之间：8px
- 文字与容器边框：12px

## 各界面设计

### 1. 主窗口
- 顶部菜单栏：文件（导入/导出/最近项目）、设置（API配置/章节规则）、帮助（使用方法/关于）
- 工具栏（可选）：导入、开始分析、暂停、导出（图标+文字按钮）
- 左侧面板：章节树形列表（280px 宽）
- 右侧主区域：QTabWidget（4个标签页）
- 底部状态栏：章节进度 / 分析状态 / API 连接状态

### 2. 章节列表面板
- 顶部：章节总数统计
- 列表：QTreeWidget，显示序号 + 标题
- 右键菜单：合并到上一章 / 合并到下一章 / 拆分为两章 / 重命名
- 双击：在主阅读区打开该章原文
- 状态图标：⚪未分析 / 🔵分析中 / ✅已完成 / ❌失败

### 3. 结果展示标签页

**原文标签页：**
- QTextBrowser，只读模式
- 顶部显示当前章节标题
- 支持 Ctrl+滚轮 缩放字号

**章节大纲标签页：**
- 左侧章节快捷跳转列表（窄）
- 右侧卡片式展示五个要素：
  ```
  ┌────────────────────────────┐
  │  第一章 · 大闹天宫          │
  ├────────────────────────────┤
  │  **激励事件**  ...内容...   │
  │  **进展纠葛**  ...内容...   │
  │  **危机**      ...内容...   │
  │  **高潮**      ...内容...   │
  │  **结局**      ...内容...   │
  └────────────────────────────┘
  ```

**阶段总结标签页：**
- 每 50 章一栏，可折叠展开
- 栏头显示：阶段 N（第 X-Y 章）

**全书故事线标签页：**
- 顶部：全书核心冲突一句话总结
- 中间：故事线时间轴式展示
- 底部：导出按钮

### 4. 设置对话框
- 模态对话框（500 × 400 px）
- API 配置区：API Key 输入框（密码模式）、模型选择下拉框、连接测试按钮
- 章节规则区：预设规则复选框 + 自定义正则输入框
- 分析设置区：超时时间、重试次数、每阶段章数（默认 50）
- 底部：保存 / 取消 按钮

### 5. 进度组件
- 分析时显示在状态栏上方或侧边栏底部
- QProgressBar + 百分比文字
- 当前分析章节名称
- 预计剩余时间（简单估算）
- 暂停 / 继续按钮
