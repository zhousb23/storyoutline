## 遇到的问题

1. Windows 终端 GBK 编码导致 print 中文乱码
   - 解决：在脚本开头添加 `sys.stdout.reconfigure(encoding="utf-8")`
2. pip 无法读取含中文路径的 requirements.txt
   - 解决：直接通过命令行安装包名，跳过 requirements.txt 文件
3. Python 安装后 WindowsApps 别名优先导致 `python` 命令不可用
   - 解决：使用完整路径调用 Python
4. prompts.py 中中文引号与 Python 三引号冲突导致语法错误
   - 解决：将中文双引号替换为「」角括号
